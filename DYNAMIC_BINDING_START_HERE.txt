5-STEP WORKFLOW (All Steps Unified)

Step 1: Create Purchase Request
└─ POST /submit_purchase_request_binding.php
   Creates entry in entries table (single source)

Step 2: Approval
└─ POST /workflow_step_binding.php?step=2
   Updates ApprovalStatus, ApprovedBy, ApprovedDate

Step 3: Notice of Delivery
└─ POST /workflow_step_binding.php?step=3
   Updates DeliveryNotes, DeliveryDate, DeliveryStatus

Step 4: Inspection & Acceptance
└─ POST /workflow_step_binding.php?step=4
   Updates InspectionNotes, InspectionDate, InspectionStatus

Step 5: Conditional Form (ICS/PPE)
└─ POST /workflow_step_binding.php?step=5
   Stores FormData (auto-determines ICS if < 50k, PPE if >= 50k)
